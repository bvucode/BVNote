# BVNote

**Lightning-fast, local-first Markdown note-taking app.**

## Principles

*   **Live Split-View:** Two panes open instantly upon file selection — text editor on one side, real-time preview on the other. See your results as you type.
*   **Local-first & No DB:** No accounts, no sync, no internet required. Your notes are stored securely as plain `.md` files in a local folder.
*   **Workspace Search:** Search across your selected workspace directory.
